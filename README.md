# letstesttools.dev

Official website for **LetsTestTools** — *Tools for testing. Built by testing the tools.*

Live at: **[https://letstesttools.dev](https://letstesttools.dev)**

## Features

- **Industrial Developer Aesthetic**: Zero generic AI gradient slop; clean slate/obsidian palette with engineering grid accents.
- **Dual-Meaning Philosophy**: Highlights testing as both an adjective (producing testing tools) and a verb (stress-testing developer tools).
- **Interactive Property Fuzzing Simulator**: Live browser simulation of generation, assertion failure, AST shrinking, and `.hegel/` persistent database caching.
- **Verified Publisher Hub**: Direct references and badges for `hegeltest` and `hegeltest_flutter` on pub.dev.
- **Zero-Dependency Static Architecture**: Pure HTML5, CSS3, and modern vanilla JavaScript.

## Local Development

Preview locally using any static web server:

```bash
python3 -m http.server 8000
# or
npx serve
```

Then visit `http://localhost:8000`.

## Deployment

Hosted on **GitHub Pages** via the `LetsTestTools/letstesttools.github.io` repository with a custom domain `letstesttools.dev` configured in `CNAME`.
